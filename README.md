# starc
---  StarC Language — A System Programming Language Self-Developed by Individual Developer Jianhun + AI Agent  Project Background  In mainstream ecosystems like Node.js, Python, and Java, a simple file operation often requires importing hundreds of dependency packages. Developers face not only dependency bloat, but also version conflicts, authors deleting repositories, packages discontinued, and malicious code injection — countless projects have been halted by these risks, yet no one can be held accountable for these "supply chain disasters."  StarC Language was born from this.  Project Positioning  StarC is a cross-platform system programming language with its compiler written in C and its runtime library fully self-developed. It is not a refinement of existing languages, but a ground-up redesign — no third-party package managers, no inherited technical debt, and only one focus: making system programming simpler, more controllable, and more reliable.  Development Journey  Phase 1: Theoretical Foundation — Building the Cornerstone  The core of StarC is its self-developed runtime library. The initial target is 5,000+ functional modules, covering file operations, process management, network communication, system monitoring, encryption and decryption, directory synchronization, log processing, cache services, permission management, and every other aspect of system programming. Currently, 70+ modules have been released, with more to come.  Meanwhile, 1,000+ example codes have been written to help developers get started quickly.  Phase 2: Compiler Handcrafting — From Zero to One  StarC's compiler starc is handcrafted in pure C, featuring a complete lexer, parser, and code generator. The compilation process relies on no third-party tools — only a C compiler (GCC/MinGW) is needed to build it.  Phase 3: Bootstrapping — Compiling StarC with StarC  The StarC compiler has achieved self-hosting capability — meaning StarC can compile its own source code. This marks the language's maturity.  Phase 4: Ecosystem Expansion — Slowly Filling the Gaps  StarC will continue to expand its ecosystem, with future plans to launch derivative languages such as StarX, StarZ, StarN, StarA, covering a wider range of application scenarios.  StarC Core Advantages  1. Minimal Code: For the same functionality, StarC's code volume is only 1/10 to 1/100 of other languages. Where others require millions of lines and hundreds of MB, StarC needs only tens of thousands of lines and hundreds of KB. 2. Real and Reliable: Except for large-scale data generation and extremely high-complexity tasks, StarC rarely uses simulation or placeholders — all features are fully implemented and real. 3. Zero Dependency Risk: No package manager, no third-party dependencies, and no worries about "repository deletion" or "version conflicts." All code is fully under your control. 4. Cross-Platform: Supports both Windows (MSYS2) and Linux — one codebase, run everywhere. 5. Continuous Expansion: StarC is the beginning, not the end. The future will see StarX, StarZ, StarN, StarA, and other programming languages, building a complete Star language ecosystem.  Goal  "As long as someone is using it and continuing to develop it, that is the greatest encouragement to me."  The ultimate goal of StarC is not to become "the most popular language," but to become "the most reliable language" — freeing developers from dependency hell and bringing system programming back to its essence.  ---  StarC is open source.
